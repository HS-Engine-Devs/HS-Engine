[h1]
Creating a Mod Folder
[/h1]

[text]
Create a folder inside mods/ or place a ZIP archive directly inside mods/. A typical
mod has this structure:

[/text]

[code]
mods/
   my-mod/
      mod.json
      icon.png (optional)
      data/
         songList.txt
         charts/
         characters/
         stages/
         weeks/
      images/
      songs/
      videos/
[/code]

[image]
src=img/shitty-cr.gif

[/image]

[text]
Add mod.json to the mod root. Its name, description, author, and version appear in the
Mod Library. The root icon.png is optional.
[/text]

[code]
{
   "name": "My Mod",
   "description": "A short description.",
   "author": "Your Name",
   "version": "1.0.0"
}
[/code]

[text]
ZIP archives are read directly and are not extracted. Files can be at the archive root
or inside one wrapper folder matching the ZIP name, with or without its .zip suffix.
Use Up/Down or the mouse wheel in the Mod Library to browse, Enter to toggle a mod,
R to refresh the list, and 7 to open the editor.

[/text]

[image]
src=img/crmod.png
scale=0.4
y=-20

[/image]

[text]
The game reads enabled mods from mods/ when they are loaded. New mods are enabled by
default when Automatically Enable New Mods is turned on.
[/text]
