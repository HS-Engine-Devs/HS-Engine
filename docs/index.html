HS Engine is a HaxeFlixel-based Friday Night Funkin' engine with custom content, in-game editors, and a built-in mod system. This guide takes you from an empty folder to a working mod.

08 GETTING STARTED

Make your first mod

Create a directory inside the game's mods/ folder. The directory name is its internal ID; use a short, unique name with lowercase letters, numbers, and hyphens.

01

Create the mod directory

For example, mods/my-first-mod/.

02

Add a manifest

Create mod.json in the mod root so the library can show its name and details.

03

Add content

Put songs, charts, images, or scripts in the matching folders under data/, images/, and songs/.

04

Launch and enable

Open the Mod Library and press Enter on your mod to toggle it.

i

The game can also read a ZIP mod placed directly in mods/. See ZIP packages for accepted archive layouts.

10 MOD IDENTITY

Describe it with mod.json

The manifest lives at the mod root. The Mod Library reads its display name, description, author, and version. All fields are optional; missing values use sensible defaults.

mod.json
{
	"name": "My First Mod",
	"description": "A short summary shown in the Mod Library.",
	"author": "Your Name",
	"version": "1.0.0"
}
nameDisplay nameShown as the mod title.
descriptionSummaryDisplayed in the details panel.
authorCreatorPlain text attribution.
versionRelease labelFor example, 1.0.0.

icon.png is optional. Place it beside mod.json; the Mod Library displays it when available.

02 FIRST: FREEPLAY

Register songs

Create data/songList.txt. This is the supported location. Add one song per line using colon-separated fields:

data/songList.txt
song-name:icon-name:week-number
song-name:icon-name:week-number:easy,normal,hard
FIELDMEANINGEXAMPLE
song-nameSong/chart folder namecool-beat
icon-nameFreeplay health iconbf
week-numberWeek index0
difficultiesOptional comma-separated listeasy,normal,hard

If difficulties are omitted, the engine uses Easy, Normal, and Hard. Keep the song name aligned with its chart directory under data/charts/.

03 CHARACTERS

Add a playable character

Create data/characters/my-character.json and put its Sparrow sprite atlas in images/characters/. Set spritePath to the atlas path without the extension, and make each animation name match a prefix in the atlas XML.

data/characters/my-character.json
{
	"animations": [
		{"anim": "idle", "name": "My Character Idle", "fps": 24, "loop": true, "indices": [], "offsets": [0, 0]},
		{"anim": "singLEFT", "name": "My Character Left", "fps": 24, "loop": false, "indices": [], "offsets": [0, 0]},
		{"anim": "singDOWN", "name": "My Character Down", "fps": 24, "loop": false, "indices": [], "offsets": [0, 0]},
		{"anim": "singUP", "name": "My Character Up", "fps": 24, "loop": false, "indices": [], "offsets": [0, 0]},
		{"anim": "singRIGHT", "name": "My Character Right", "fps": 24, "loop": false, "indices": [], "offsets": [0, 0]}
	],
	"spritePath": "characters/my-character",
	"healthIcon": "my-character",
	"scale": 1,
	"flipX": false,
	"antialiasing": true,
	"singDuration": 4,
	"cameraOffset": [0, 0],
	"characterOffset": [0, 0]
}

Put the health icon at images/icons/my-character.png. Animation anim is the name used by the engine; animation name is its atlas prefix. Tune offsets and scale for your sprite.

04 STAGES & BACKGROUNDS

Build a stage from image layers

Create data/stages/my-stage.json. Each entry in objects places an image in the scene. The image path points into images/ and omits the .png extension.

data/stages/my-stage.json
{
	"objects": [
		{
			"name": "background",
			"position": [0, 0],
			"image": "stages/my-stage/background",
			"scrollFactor": 0.9,
			"antialiasing": true,
			"alpha": 1,
			"layer": 0,
			"scale": 1
		}
	],
	"defaultCamZoom": 0.9,
	"bfPosition": [770, 100],
	"gfPosition": [400, 130],
	"dadPosition": [100, 100]
}

Save the image as images/stages/my-stage/background.png. Use layer 0 for the regular scene and 1 for foreground objects. Add more entries to create parallax scenery; each object has its own position, scroll factor, scale, and transparency.

05 STORY WEEKS

Group songs into a week

Add a JSON file under data/weeks/ to define a Story Mode week. Song names must match your chart/song folders; character values are character IDs.

data/weeks/my-week.json
{
	"name": "My Week",
	"texture": "my-week",
	"songs": ["cool-beat"],
	"characters": ["bf"],
	"difficulties": ["easy", "normal", "hard"],
	"color": "9271FD"
}

The texture value selects the week menu artwork. Set color to the week accent color; it is optional. Add the matching week artwork and ensure every listed song has its chart and audio files.

11 DISTRIBUTION

Package as a ZIP

Put the archive directly inside mods/. The engine indexes and reads entries without extracting the archive.

FLAT ARCHIVE
my-mod.zip
├── mod.json
├── icon.png
└── data/...
WRAPPED ARCHIVE
my-mod.zip
└── my-mod/
		├── mod.json
		├── icon.png
		└── data/...
!

A wrapper folder must match the archive name, with or without the .zip suffix. Avoid nesting unrelated folders inside the archive.

06 SCRIPTING

Script the gameplay lifecycle

HS Engine runs mod scripts with HScript, a lightweight scripting language with Haxe-like syntax. Scripts are loaded into gameplay in this order: the current song's chart script, each enabled mod's data/scripts/*.hx files, then the current stage script.

data/charts/<song>/script.hxOnly for the matching song
data/scripts/<file>.hxLoaded for gameplay from each enabled mod
data/stages/<stage>.hxOnly for the active stage

Define a function using a hook name below. The engine calls it automatically. Hook return values are ignored; change game objects or use the provided helpers to affect gameplay.

data/scripts/beat-camera.hx
function createPost() {
	FlxG.log.add("My mod script is ready");
}

function beatHit(beat) {
	if (beat % 4 == 0) {
		camHUD.zoom += 0.02;
	}
}

Custom states and substates

Place state scripts in data/states/ and open one with switchState("MyState"). Put substates in data/substates/ and open them with openSubState("MySubstate", true). Both support create, createPost, update(elapsed), updatePost(elapsed), stepHit(step), and beatHit(beat). They also receive members, controls, curBeat, curStep, and this.

!

HScript exposes filesystem access and powerful engine objects. Scripts are not sandboxed; only run code from sources you trust. HScript syntax is similar to Haxe but is not a full Haxe compiler.

13 QUICK FIXES

When something is missing

My song does not appear in Freeplay

Check that the list is at data/songList.txt, that each line uses colon-separated fields, and that the mod is enabled.

The song appears, but its chart cannot load

Check the chart under data/charts/<song-name>/ and make sure the chart filename matches the song and selected difficulty.

The ZIP is listed but its files are not found

Use a flat archive or one wrapper folder matching the ZIP filename. Confirm paths and capitalization inside the archive.

The Mod Library shows fallback metadata

Put a valid JSON mod.json at the mod root. Its name, description, author, and version values should be strings.
